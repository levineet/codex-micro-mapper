# Security

## Report a vulnerability privately

Please use **Security → Report a vulnerability** in this repository if that option is available. Describe the affected version, reproduction steps, impact and a minimal example without personal data. Do not post an exploit or private input in a public issue.

If private reporting is unavailable, open an issue asking only for a private reporting channel, without vulnerability details. The maintainer will arrange a channel. This is an independent project; no response-time guarantee or paid support is offered. Fixes target the latest release.

Issues involving keyboard capture, event injection, input focus, unintended deletion, permission handling or untrusted configuration are especially relevant. Permissions are broad: inspect the [privacy explanation](PRIVACY.md) and code before granting them. Download binaries only from this repository's Releases, verify checksums, and check the stated signing/notarization status. Build from source if you prefer.

## 安全问题

如发现漏洞，请优先使用仓库的 **Security → Report a vulnerability** 私下报告，提供受影响版本、复现步骤、影响和不含个人信息的最小示例。不要在公开 Issue 中发布漏洞细节、利用代码或私人输入内容。

若入口不可用，请仅创建一个“申请私下报告渠道”的 Issue，不包含漏洞细节，由维护者安排沟通方式。本项目独立维护，不承诺响应时间或付费支持；修复面向最新版本。

特别关注按键录制、事件发送、焦点变化、误删文字、权限和配置解析问题。授权前可阅读 [隐私说明](PRIVACY.zh-CN.md) 和源码。安装包仅从本仓库 Releases 获取，并核对校验和及签名、公证状态；也可以自行构建。
