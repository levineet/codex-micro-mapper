# Third-party names and assets

The Swift package has no third-party package dependencies. It uses Apple's system frameworks and renders SF Symbols through the macOS system APIs; SF Symbol image files are not distributed as an asset library.

Work Louder, Codex Micro, Codex, ChatGPT, Google Chrome, Typeless and other product names identify compatible hardware or example mapping targets. They belong to their respective owners. This project is independent and is not endorsed by those companies.

App icons in the mapping interface are obtained from apps already installed on the user's Mac through `NSWorkspace`. Third-party app icon files are not bundled in the source or app. Documentation screenshots show those icons only as part of the actual interface; the project license does not grant rights to those third-party marks.

`CodexMicroMapping.icns` is the project's supplied app artwork. The documentation icon is a resolution from that same file. Unused vendor layout references and historical design screenshots are excluded from the public package.
